\# Team 6 Integration API



A Node.js and Express backend for Team 6 integration with tenant management and WhatsApp webhook processing.



\## Features



\- Health check API

\- Tenant/client management

\- Client CRUD operations

\- Token-based API authentication

\- PostgreSQL database

\- Prisma ORM

\- WhatsApp webhook handling

\- Meta WhatsApp API integration

\- Meta test mode for development

\- GitHub Actions CI pipeline



\## Technologies



\- Node.js

\- TypeScript

\- Express.js

\- PostgreSQL

\- Prisma

\- Axios

\- GitHub Actions

\- Meta WhatsApp API
